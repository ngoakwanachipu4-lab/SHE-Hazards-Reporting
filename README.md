# SHE-Hazards-Reporting
Analysis of the reported Safety, health and Environmental (SHE) hazards in a workplace over a period of 5 months
For this project, I wanted to demonstrate how raw SHE (Safety, Health & Environment) hazards reporting data can be transformed into meaningful insights that support better decision-making.
I started with Canva to plan the project and define what the final solution should communicate. Before jumping into visualisations, I used Miro to map the dataset flow and think through how the different data elements should connect.
From there, I used SQL to process and analyse the datasets — inspecting the data, transforming fields, categorising information, and preparing the data for reporting.
The final stage was Power BI, where I transformed the processed data into an interactive SHE Hazards Reporting Dashboard.
The dashboard provides visibility into:
📊 Total hazards reported
📅 Hazards reported over time
⚠️ Hazard categories
🏭 Operations contributing to reported hazards
📍 Specific locations
🔎 Sub-operations contributing to hazards
📈 Trends that can help identify areas requiring further investigation
One of the key things this project reinforced for me is that good dashboards start long before Power BI.
The real value comes from understanding the business question, understanding the data structure, designing the data flow, applying the right transformations, and then choosing visualisations that communicate the story clearly.
My workflow for this project:
Canva → Project Planning
↓
Miro → Data Flow & Process Mapping
↓
SQL → Data Processing & Analysis
↓
Power BI → Interactive Dashboard & Insights
This project allowed me to combine my interest in SHE/ESG with data analytics, demonstrating how organisations can move from simply collecting incident and hazard data to using that data to identify trends, understand operational risk and support data-driven decision-making.
I’m continuing to build projects that combine SQL + Python + Power BI + ESG/SHE analytics to solve practical business problems.
